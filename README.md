### [Versum](https://github.com/eduardoaugustolb/versum)

A multi-platform Bible reader for reading at your own pace, without a feed, likes, or rankings. Planned features include synced progress, offline reading on Android, and chapter and verse sharing.

Pre-alpha · Go, PostgreSQL, Redis · Next.js and React Native / Expo planned.

### [Affiliate Hub](https://github.com/eduardoaugustolb/affiliate-hub)

Automation for a streetwear and fragrance affiliate profile: product and link syncing, post image generation, and distribution to a WhatsApp group.

In progress · TypeScript, Bun · Clean Architecture and Hexagonal Architecture.
